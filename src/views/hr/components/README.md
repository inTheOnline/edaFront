# 人事首页工具栏

- 网络检测明细包含名称、检测地址、检测结果；名称对应百度（www.baidu.com）、B区（192.168.0.110）、C区（192.168.0.16）、网关（192.168.0.1）。

- `NetworkTool.vue`：网络检测按钮和结果弹窗，POST `/hr/network/check`，由 ERP 服务器依次 ping `www.baidu.com`、`192.168.0.110`、`192.168.0.16`。每个地址发送一次，响应等待2秒，进程最多4秒，前端请求超时25秒。服务器需安装可执行的 ping 命令（Windows/Linux）。
- 百度通：网络正常；百度不通、110通16不通：A区网络异常；百度不通、110不通16通：B区网络异常；三个都不通：C区或者B区网络异常。
- 只有百度不通、110和16都通时继续 ping `192.168.0.1`，网关通提示路由器异常，网关不通提示网关问题。弹窗显示逐项通断；执行错误独立提示检测失败，不作为网络故障结论。

- `LeaveSalaryTool.vue`：首页工具栏、离职工资计算弹窗、记录列表和记录详情。
- `LeaveSalaryTable.vue`：计算预览和历史记录共用的工资表，列顺序与后端 Excel 一致。普工额外展示三类工时和对应工资。
- 使用 Element Plus 表单、弹窗、表格，沿用首页 Naive UI 卡片。数字输入隐藏步进按钮。
- 职员按姓名或工号远程搜索，读取数据库工资标准；职务手填。月薪支持选择208或260小时，普工固定176小时。
- 表单变化延迟250毫秒请求预览，丢弃过期响应。等待预览、切换职员或预览失败时禁用保存和导出。
- 社保默认读取职员档位，仅支持未购买、一档、二档。未购买切换为购买时默认二档，可手改一档，不回写职员。
- 导出通过 `http.download`、`useDownload` 下载；识别 JSON 错误响应，避免将业务错误下载成 Excel。
- 只有“保存”调用保存接口，成功后关闭弹窗。取消、关闭、导出不写记录。保存过程中禁用取消、关闭和表单编辑。
- 保存的记录不可在此页面修改；详情和再次导出使用保存时的快照，不重新读取职员工资标准。

## 接口

统一前缀 `/hr/leaveSalary`，封装于 `src/api/modules/leaveSalary.ts`：

- GET `/staff?keyword=`：最多50条姓名/工号搜索结果。
- GET `/initial?staffId=`：初始化工资标准、计薪类型、社保、结算标识。
- POST `/preview`：计算结果及预览摘要。
- POST `/export`：核对预览摘要，下载 Excel，不写入数据库。
- POST `/save`：核对预览摘要并保存；同一结算标识重复请求返回原记录。
- GET `/page?pageNum=&pageSize=&keyword=`：按保存时间、ID倒序查询。
- GET `/detail?id=`、POST `/record/export`（`{ id }`）：查看、导出保存的快照。
