# 包装日报表

## 功能
- 路由 `/production/packReport`，位于生产系统下，与生产日报表平级。
- 一组由日期、员工、共用工时和多条明细组成。多产品共用工时只存一次；另一次工时新建一组。
- 支持新增、查看、整组编辑、逻辑删除、批量删除、日期/员工/产品/工序/备注筛选、选中组数量与工时合计。
- 筛选命中任一明细后返回整组，分页和选择均以组为单位，不对共用工时分摊。
- 产品、员工复用系统字典；产品编号和名称联动。辅助作业允许不选产品、数量不填。
- 15个一级工序可多选；检验与包装提供可选的阶段/方式。旧叫法可搜索对应一级工序，出差地点、异常等填备注。
- 桌面Excel只用于设计，历史记录未导入；本页面不参与生产效率计算。

## 技术与接口
- ProTable + PackDrawer + ProcessSelect；主列表每行显示一组，多明细在对应单元格内按行对齐。
- `POST /packReport/getAll` 分组分页，`GET /packReport/{id}` 完整组详情。
- `GET /packReport/processes` 后端统一的工序选项与旧叫法搜索关键词。
- `POST /packReport/add`、`PUT /packReport/edit` 保存组；编辑携带revision防止覆盖他人修改。
- `POST /packReport/deleteBatch` 整组逻辑删除。写入失败由后端事务整体回滚。
- 后端通过角色路由权限校验所有接口，初始化菜单脚本沿用生产日报可见角色，之后可独立调整权限。
- 对应后端迁移 `sql/20260914_pack_report.sql`。没有修改生产日报表、工序或历史数据。

## 注意
- 共用工时不能复制到每条明细累计，数量等按明细累计。
- 工序大类与阶段分别保存，不允许自由创建叫法；维护选项应修改后端PackProcesses统一来源。
- 数量、不良、报废各自非负，不自动推断相互包含关系。
- 本次不提供历史导入按钮，后续导入须处理合并工时、产品/员工匹配和工序归并。
