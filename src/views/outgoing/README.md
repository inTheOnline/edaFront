# outgoing 模块主页

## 目录说明
- `index.vue`：外发模块首页（可视化 + 工具入口 + 待办预留）
- `outform`：外发录表
- `outback`：外发回货
- `supWork`：供应商工费（本轮未改动）
- `service.ts`：outform/outback 统一请求入口

## 本轮更新（2026-04）
- 恢复并保留首页工具入口中原有可用能力（供应商扣款处理、供应商报价导入）
- `outform`：
- 批量新增新增“前缀+单号”拼接规则
- 操作列“查看”改为大窗显示回货明细
- 删除确认改为大窗显示关联回货明细并二次确认
- `outback`：
- 批量选择外发明细支持多选并批量带入
- `state` 字典统一归一化处理，修复状态列和状态下拉空白问题

## 接口文档
- 工具箱提供相邻的“供应商扣款处理”和“供应商扣款（含电镀费）”，共用模板、文件名校验和上传流程。
- 含电镀费入口向 `/outgoing/getDeductions` 传 `includePlatingFee=true`；不论是否退素材，原扣款公式均加当前供应商、物料、工序的报价，再按原规则将单价四舍五入到 2 位后乘数量。普通入口保持原规则。
- 以 [API.md](./API.md) 为准
- 外发首页看板接口见 [HOME_API.md](./HOME_API.md)

## 首页真实数据（2026-09）
- 首页通过 `home.ts` 调用 `/outgoing/home/summary` 和 `/outgoing/home/trend`，不再使用模拟数据。
- 总览显示本月外发、本月已提交回执、全部待回执数量及活跃供应商；排行取待回数量前 8 名。
- 趋势支持单个供应商、单个料号、起止日期及月 / 日切换，并提供统计明细表。
- 供应商与物料通过 `/outgoing/home/options` 按期间业务记录双向联动；已选另一项时只展示有对应记录的候选。
- 草稿、作废、已删除回执不计入首页数量；移除模拟环比和模拟工具动态。
