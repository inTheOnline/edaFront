# outgoing/outform 外发表页

## 阅读顺序
- 先看 `index.vue`
- 再看 `components/UserDrawer.vue`、`components/BatchAddDialog.vue`、`components/OutbackDetailDialog.vue`
- 接口定义在上级目录 `../service.ts`

## 当前功能
- 外发表分页查询
- 单条新增、编辑、删除
- 批量新增
- 按整张单据开委外单、整单编辑及模板 PDF 打印
- 开退货单：仍保存为委外单，整单备注自动包含“退货返工”，明细增加独立退货原因并使用退货单版式打印
- 按当前筛选条件导出全部委外表单数据为 Excel，不受列表分页限制
- 批量删除前展示“关联回货明细”并二次确认
- 操作列“查看”使用详情弹窗展示当前 item 的回货明细

## 导出约定
- Excel 表头使用列表中文列名，不导出选择、序号和操作列
- 导出列为：外发日期、外发单号、供应商、物料编码、物料名称、外发数量、已回货数量、未回货数量、状态、整单备注、行备注

## 当前交互约定
- 列表页支持点击整行勾选当前项，行为与勾选框同步
- 列表头部紧凑显示已勾选记录的 `number/backNumber/notbackNumber` 三项求和，样式参考 `production/dailySheet`
- 列表头部提供“取消选择”，可一键清空当前已勾选记录
- 单条表单中的供应商、物料、状态选择支持整块点击展开
- 搜索栏中的供应商、物料编码、状态下拉基于 `/outgoing/outform/page` 全量委外记录去重生成，并按已选下拉条件互相联动；全量记录读取失败时回退到原字典选项
- 新增、编辑、批量新增、删除后会刷新列表和搜索下拉全量数据

## 批量新增规则
- 表头拆分为：
- `外发前缀`：只读，随供应商自动带出
- `外发单号`：手输
- 实际提交单号：`外发前缀 + 外发单号`
- 行明细包含 `materId/number/state/remark`

## 开委外单

- 单位、小工艺和包规均由后端接口 `/outgoing/order/options` 返回；料号涉及的大工艺兼容读取 `mater_work` 与已有供应商报价，再返回这些大工艺下的全部小工艺。
- 包装开关默认关闭；开启后按包规自动计算，数量仍可人工覆盖。
- 打印与原材料采购单共用前端 `pdfMake` 生成方案，在新窗口预览并调用系统打印框。
- 纸张尺寸为 240×140mm，抬头、表格、右侧联次和底部签收栏按现有纸质委外单版式生成，明细行随数据自动增减。

## 开退货单

- 复用委外单的供应商、日期、系统单号、打印编号、物料、小工艺、单位和数量规则。
- 整单备注自动保留“退货返工”标记，列表据此进入退货单编辑及打印。
- 明细列为：物料编号、物料名称、加工工艺、退货原因、单位、数量、备注。
- 打印复用委外单的前端 `pdfMake` 生成方案和版式，标题为“退货单”，明细表保留退货单现有字段。

## 未回数量展示
- 列表页 `未回货数量` 使用胶囊样式展示
- 当 `未回货数量 < 0` 时，单元格高亮，便于识别异常委外单
