# 祥鑫系统操作

输入祥鑫账号、密码和包装箱条码，查询箱内全部物料，再确认批量删除。关闭状态先解包装，逐条移除，结束后确认空箱。仅移除箱内物料，不删除包装箱或物料基础档案。

使用 Element Plus 表单与表格，沿用 ERP 主题。密码只保存在页面内存，不写入浏览器存储；sessionStorage 仅保存任务 ID，刷新页面后恢复进度。菜单权限标识 `xiangxin`，路由 `/xiangxin`，组件 `/xiangxin/index`。

后端接口：POST `/xiangxin/preview`（account/password/carton）、POST `/xiangxin/start`（id）、GET `/xiangxin/progress?id=...`。调用现有 http 封装，进度请求关闭全屏加载。

查询有效期 15 分钟；后台任务只接受其 ERP 创建者访问，同一任务重复启动不会重复删除。全局同时执行一个批次。执行前复查物料与状态，有变化则停止；每条移除后重新查询确认。失败不自动重试，需要重新查询实际结果。服务重启后内存任务失效，需重新查询。查询时显示的状态不代表执行后的箱状态。
