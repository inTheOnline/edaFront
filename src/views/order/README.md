# 订单首页

## 功能内容

- 有 `price:view` 权限时，首页先展示经营分析：当月净营业额、年度累计、当月退货金额、当前待交估算；年度折线支持公司/客户切换，月度客户占比支持点击下钻，产品构成随客户和月份筛选。
- 补充同日同比/环比、TOP3 客户集中度及客户营业额变化贡献。客户占比和集中度始终为公司口径；其余指标跟随客户筛选。产品构成为所选月份，年度累计为所选年截至今日，当前待交为实时余额。
- 保留原经营概览，点击标题下拉可切换到独立“毛利分析”视图：材料费、外发费用、月毛利及毛利率卡片，下方按月展示营业额、材料费、外发费用、固定费用、毛利、毛利率和数据状态，并显示服务端年度累计。两个视图不混排，下方订单工作台不受影响。
- 默认仍进入经营概览、全部客户；首次进入毛利分析默认胜蓝。两个视图分别保存客户筛选，切回经营概览恢复此前客户；年份和月份共用。毛利视图选其他客户时只展示待开放说明，可通过“查看胜蓝”切回。
- 无 `price:view` 权限时不挂载经营分析组件、不请求金额接口，仍可使用下方订单工作台。
- 展示全部订单数、待交物料明细数、全部物料明细数、出货及退货明细记录数。
- 默认展示待交订单明细，支持按订单编号搜索、切换全部明细、每页 6 条分页及只读明细弹窗。
- 展示最近 5 条出货/客户退货记录，退货数量保留负数。
- 提供订单管理、物料明细、出货与退货入口；没有对应动态路由权限时禁用入口。
- 生产页面没有示例营业额、固定环比、客诉指标或推断交期。独立设计预览明确标注“示例数据”。

## 技术实现

- `index.vue` 负责页面布局和只读详情，复用 Vue 3、Element Plus 与现有图标库。
- `components/RevenueOverview.vue` 和 `RevenueChart.vue` 负责经营筛选及 ECharts 图形；图表响应容器宽度和明暗主题，卸载时释放实例。月份/客户变化时立即清空旧金额，并用请求序号丢弃旧响应。
- `components/OrderProfit.vue` 仅在毛利分析视图挂载，复用经营分析响应中的 `profit`，不另发请求、不在前端重算成本或累计。胜蓝客户 ID 从客户字典按名称精确匹配（可回退到后端 `profit.custId`），不硬编码；组件只发出切换客户事件。切视图清空旧数据并沿用请求序号丢弃过期响应。毛利缺失显示 `—`，行内数据状态可展开核查说明；未来月份不显示金额。
- `home.ts` 负责数据请求、分页搜索、数量格式化及交付进度。样式仅作用于本页，颜色跟随已有主题。
- 概览统计全部记录，不随表格的订单编号搜索或待交/全部切换而变化。
- 表格按后端订单明细 ID 倒序，出货按日期倒序、同日明细 ID 倒序。
- 交付进度为已交数量 / 订单数量，进度条限制在 0–100%；具体数量保留接口原值。缺失或无效值显示 `—`。
- 请求失败显示明确错误，失败指标显示 `—`，不作为 0；搜索请求用序号防止旧响应覆盖新结果。
- 客户名称复用 `dict.loadDict('cust')`；字典缺失时显示客户 ID。
- 页面首次加载、从缓存标签切回和手动刷新时重新读取；只调用查询接口。

## 后端 API 与口径

- `revenue_adjust` 中的历史冲减及费用调整参与全部已实现营业额统计，按实际日期计入。`adjustment` 独立显示于月指标和月度数据中，不计入退货金额或待交估算；无关联产品的费用列为“其他调整”。

- `GET /order/revenue?year=2026&month=9&custId=...`：服务端校验 `price:view`；聚合 SQL 在数据库汇总，不下载全量出货。
- 营业额使用“实际出货数量 × 含税成交单价 − 退货金额”，退货根据发生月扣减。绑定订单明细实时读取 `order_mater.price`；游离出货读取保存的 `order_out.price`，客户同理读取订单或出货保存的客户。
- 当前月对比截至同日，历史月对比整月，短月份按最后一天截断。年度折线过去无记录显示 0，未来月份为 `null`；当期尚未结束时与上年整月折线有明确提示，同期增长率单独使用相同截止日。
- 缺价明细返回 `missingPriceCount` / `missingPriceQuantity`，只汇总已定价部分；全缺价金额为 `null`，合法零元价照常参与统计。基期金额不大于 0 或任一对比期缺价时增长率为 `null`。
- 任一客户/产品净额为负、缺价或合计不大于 0 时不画占比饼图、不计算集中度；保留原始金额。客户贡献包含上月有营业额、本月为零的客户。
- 待交估算为未完成且未交数量大于 0 的明细 × 当前订单价，与已实现营业额分开展示，不按所选月份回算历史待交。
- `getOrderAll` → `POST /order/all`：`pageNum:1,pageSize:1,createTime:null,updateTime:null`，使用 `data.total` 统计订单总数。日期必须显式清空，避免 `OrderTable` 默认日期意外过滤。该接口无稳定排序，不用于近期订单列表。
- `getOrderMater` → `POST /order/getOrderMater`：待交统计 `showCompleted:false`，全部统计 `showCompleted:true`，均以 `data.total` 统计物料明细条数，不是订单单数。
- 待交条件沿用后端：存储状态不等于完成状态且未交数量大于 0。表格搜索传顶层 `orderNum`，空搜索省略该字段；不额外传状态或默认客户。
- `getOrderOut` → `POST /orderOut/all`：`pageNum:1,pageSize:5`，`data.total` 是出货及退货明细记录数，一张送货单可能有多条记录。
- 客户名称使用已有通用字典接口。

### 胜蓝毛利估算

- 铜均价采用 CCMN 长江现货 1# 铜含税月均价，材料计算另加 5 元/kg 加工费；历史月份分别使用各月铜价，当前月为截至所示日期的暂估月均价。按当前产品重量和现有外发报价估算，历史结果会随资料或报价更新，不作为历史成本价格快照。
- `GET /order/revenue` 增加 `profit`：`supported`、`custId`、`custName`、`reason`、`throughDate`、`monthTotal`、`yearTotal`、`months`；目前只支持所选客户为胜蓝，其他范围不返回假零金额。
- 月/年汇总包含 `revenue`、`quantity`、`materialCost`、`outCost`、`fixedCost`、`grossProfit`、`margin`、`complete`、`missingWeightCount`、`missingOutCount`、`missingPriceCount`、`issues`；月记录额外包含 `year`、`month`、`future`。金额单位元，毛利率为小数比率。
- 月/年汇总增加 `copperPrice`（市场铜均价，元/kg，不含 5 元/kg 加工费，年度累计为 `null`）、`copperPriceThroughDate`（报价截止日）、`copperPriceSource`（证据 URL）、`copperPriceProvisional`（当前月暂估）、`missingCopperPrice`（年度为任一月缺铜价）。铜价和加加工费后的材料费均由后端提供，前端不计算月均值或财务结果。
- 月度表在营业额后展示铜均价，保留三位小数；当前月显示暂估、截止日期及来源链接，年度累计和未来月份铜价显示 `—`。材料费卡片展示所选月份铜均价、截止日期及来源；缺铜价明确显示待补并列入数据状态。
- 材料费＝（理论净重 kg ×（当月铜均价 + 5）+（单件毛重 kg − 理论净重 kg）× 6）× 净出货数量，材料单价含税，5 为每千克加工费；表格铜均价列仍展示未加加工费的市场均价。单件毛重不是整张板料重量。材料费和外发费用均按当月实际出货减退货的净出货数量计算，按出库/退货单日期归月；金额扣款调整不改变数量。
- 外发单数量仅用于选择供应商，不作为材料费或外发费用的成本统计数量；未注明单位的报价按元/件，元/千克报价按理论净重换算成每件价。产品涉及的工序取外发报价表全部不同工序，各工序成本相加。
- 同产品、同工序选择当月外发数量最多的供应商报价，并列最多时取平均；当月无外发，取截止该月最近有外发的月份。无历史外发、外发工序或日期等异常导致无法可靠选择供应商，或所选供应商无有效报价时，按该产品该工序现有有效报价统一为元/件后平均。成功使用均价的原因由后端写入 `issues`，不因此标记数据不完整；前端在数据状态说明中展示。
- 固定费用暂按 0 元计入，所有已发生月份均为 0，未来月份不计算。
- 营业额保留原有退货、扣款和调整口径；成本不另计扣款。毛利＝营业额 − 材料费 − 外发费用 − 固定费用；毛利率＝毛利 / 营业额，零营业额不计算毛利率。
- 任一必需成本或销售单价缺失时，后端标记 `complete:false` 并提供原因，前端不显示完整毛利或毛利率。年度累计直接使用后端汇总，年度毛利率不平均各月毛利率。

## 维护注意

- 依赖订单价格迁移字段 `order_mater.price`、`order_out.price`、`order_out.cust_id`，先完成对应迁移再启动新后端。
- 所有金额、同比、份额在后端权限检查后返回，前端隐藏仅为交互控制，不能替代后端鉴权。
- 不调用有写入副作用的 `/order/reset`，不在首页修改订单/库存。
- `lateTime` 等现有字段是完成时间，不能作为交期计算逾期。
- 主表状态、明细状态及出货状态含义不同；首页不使用外发状态字典，不按推导状态反推全局统计。
- 子页面未处理订单号路由查询参数，业务入口仅跳转模块；单条“查看”在首页弹窗中展示对应物料明细。
- 后续若增加指标，先核实数据口径和真实接口，不使用随机数或演示数据代替生产数据。
