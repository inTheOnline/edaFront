# 仓库首页

- StockOverview 展示顶部入库合计、出库合计、期末库存卡片及期初+净变动=期末。
- 仓库、产品、日期、库存类别筛选同步影响卡片与图表；默认本月至今天，清空日期查询全部。
- POST /stock/v2/overview 提供真实有效流水汇总，接口失败显示错误，不使用模拟值。
- StockCharts 显示每日出入库趋势，缺失日期补0；右侧为截至期末的库存前10项，选定产品时显示库存类别构成。
- 有日期范围时期初含开始日前流水，期末含结束日当天。与仓库统计比较时需一致的仓库、产品、类别和时间口径。
- 使用首页主题颜色、独立卡片、响应式布局；移除旧模拟图表。
