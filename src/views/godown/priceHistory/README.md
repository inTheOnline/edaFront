# godown/priceHistory 价格调整记录页

## 功能内容
- 展示物料价格调整记录。
- 支持按物料编号、物料名称、调价批次查询。
- 字段包括物料ID、物料编号、物料名称、原价、新价、价差、涨幅比例、调价批次、生效日期、调价原因、操作人、创建时间。

## 技术实现
- 页面使用 ProTable。
- 数据来自后端 `/priceHistory/getAll`。
- 创建时间显示格式为 `YYYY-MM-DD HH:mm:ss`。
- 该页面只做查询，不提供新增、编辑、删除。

## 注意点
- 调价记录由物料批量调价或历史 Excel 导入产生。
- 记录表不保存来源文件。
