# 原材料请购

## 关联订单

- 一条请购明细可关联多条内部订单明细，所关联订单必须为相同物料；顶部“选择订单条目”按物料合并为新明细并追加，保留已填内容。
- 新增和编辑中可逐行“关联订单”，已关联订单可单独移除；切换为其他物料时清除旧订单关联。订单选择支持跨页勾选。
- “订单数量”为关联订单产品数量（`totalNumber`）之和，与可调整的生产数独立；请购明细列表、整单查看、新增/编辑、Excel 和 PDF 均在“生产数”前显示。
- 保存明细提交 `orderItemIds`（内部订单明细 ID 数组）；查询返回 `orders`、合计 `orderNumber` 和汇总订单号 `custOrderNum`。后端校验订单物料一致并负责计算数量。

## 状态规则

- 状态按 `待处理 → 部分采购 → 已采购 → 部分回执 → 已完成` 流转。
- 同时存在未采购和已回执数量时，优先显示“部分回执”。
- 主表、明细表和查看弹窗中的状态统一使用语义 Tag 展示。

- 路由：`/buy/rawRequisition`
- 默认展示请购主表，可切换为请购明细。
- 主表查看展示整单明细；请购明细“查看”按 `requisitionItemId` 分页展示该明细全部有效采购记录。新增、编辑按整单保存，单号由后端生成。

- 请购重量后显示“采购数量”：板料显示累计已采购张数（张），卷料显示累计已采购重量（kg）；整单明细弹窗和 Excel 导出使用相同口径。

- 主表和明细列表均在后端分页前将“已完成”记录排到最后，各组内按 ID 倒序。
- 卷料按实际重量差判断采购完成：已有采购且请购重量减累计采购重量 ≤ 0.1 kg 时视为已采购，不先四舍五入；回执状态仍优先。

- 主表、明细及 Excel 导出在状态后显示请购人姓名，使用已保存的 `applyUserId` 对应用户姓名；未记录请购人的历史单据不推断人员。

- 普通新增和跨模块快速请购统一记录新建时的登录用户为请购人；编辑保持原请购人，历史空值不补填。请购主表和明细在状态后显示请购人姓名。
