# 原材料回执

- 状态统一使用语义 Tag 展示，保存、编辑或删除回执时同步刷新采购单和请购单状态。

- 路由：`/buy/rawReceipt`
- 默认展示回执明细，可切换为回执主表。
- 一张回执可对应多张采购单，支持部分和多次回执，保存后写入原材料库存。
- 明细列表支持点击整行勾选；顶部汇总所选明细的回执重量，并可一键取消选择。
- 回执重量表头为“回执重量（kg）”；其后、备注前显示单价（两位小数）。列表、查看及新增/编辑弹窗仅对 `price:view` 用户显示单价，Excel 导出同步控制。单价只读，每次查询从关联采购明细读取当前 `unitPrice`，不在回执中保存价格快照。

- 回执单号由用户手动填写，不能为空；材料数与重量独立输入，不再互相换算。
- 回执明细和导出显示回执日期、对应采购单号，不显示原材料编号。

- 回执主表、明细及 Excel 导出列顺序为回执日期、回执单号、供应商、采购单号，明细供应商来自关联采购单；新增和编辑回执顶部四个字段在桌面宽度下一行显示，窄屏自动换行。

- 新增回执的采购单下拉隐藏已完成回执的采购单，每次打开重新加载；编辑时保留当前回执已关联的采购单。

- 新增明细显示物料编码；增减采购单保留仍选中采购单的已填明细，避免覆盖数量、重量和备注。

- 明细分页使用关联查询：物料编码、名称来自采购明细，回执单号及整单备注来自回执主表，采购单号来自采购主表；筛选和总数统计使用相同条件。
