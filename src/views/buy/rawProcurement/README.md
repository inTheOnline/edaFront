# 原材料采购单据共用页面

## 功能

- 请购单、采购单、回执单共用 `RawDocumentPage.vue`。
- 从其他缓存标签页返回时重新读取当前列表，及时展示采购、回执删除后的数量与状态；首次显示沿用 ProTable 的初始化请求。
- 默认按明细展示，可切换为主表展示；两种展示均支持搜索、分页、查看、编辑、删除、批量删除和 Excel 导出。
- 明细视图中的编辑、删除操作作用于该明细所属的整张单据。
- 点击主表单号或“查看”显示整张单据及其明细；原材料采购明细行的“查看”例外，按 `purchaseItemId` 调用回执明细分页接口，展示该条采购明细的全部有效回执，单价沿用价格查看权限。
- 明细维护生产数、材料数和重量；板料显示单位“张”，卷料显示单位“卷”，单位只在前端展示。
- 板料读取关系表 `sheet_weight`（kg/张），卷料读取关系表 `gross_weight`（g/个）；卷料材料数默认 1。
- 请购单可从订单系统选择物料订单条目，采购单每次打开时重新读取未采购请购明细。
- 请购明细支持多订单关联，同一行只能关联相同物料的订单；批量选择按物料分组追加，行内支持增减关联。明细使用 `orderItemIds` 保存订单明细 ID，`orders` 回显关联，`orderNumber` 为关联订单产品数量之和，显示在“生产数”前并用于 Excel 和请购 PDF。
- 首次采购选择请购明细时，采购重量默认等于请购重量；编辑已有采购单时保留当前已绑定请购项的下拉标签，即使该请购项已无剩余量。
- 卷料按请购重量与累计采购重量判断剩余量，部分采购后再次选择时默认带入剩余重量；板料继续按材料张数判断。两类原材料均允许超采。
- 卷料已有采购且累计采购重量距请购重量不超过 0.1 kg（含边界）时，按已采购判断并从未采购选项移除；实际重量和差额保持原值，编辑时保留已关联项。板料张数及回执完成规则不变。
- 回执选择采购单后，回执重量默认带入剩余未回执重量；生产数带入剩余生产数并设为只读。卷料回执完成状态按重量判断。
- 订单物料没有维护原材料关系时，在订单条目选择弹窗中标红并禁用勾选，点击该行会直接提示原因。
- 原材料采购明细支持点击整行勾选，按重量汇总所选明细的采购、已回执和待回数据，并可一键取消选择。
- 原材料回执明细支持点击整行勾选，汇总所选明细的回执重量，并可一键取消选择。
- 订单主表的“快速请购”会复用本页的字段和原材换算规则，通过 `/buy/quick-requisition/*` 与辅材请购事务性创建；快速请购允许选择缺少原材关系的订单 Item，由预览统一警告并继续生成已有类别。
- 请购单与采购单统一使用 `src/modules/document-pdf` 在浏览器中生成 PDF，业务模板位于 `../utils/requisitionDocumentPdf.ts` 和 `../utils/purchaseDocumentPdf.ts`。

## 后端接口

- `/buy/raw/{kind}/table/page`
- `/buy/raw/{kind}/item/page`
- `/buy/raw/{kind}/{id}`
- `/buy/raw/mater/options`

其中 `{kind}` 为 `requisition`、`purchase` 或 `receipt`。

- 回执单号由用户手动填写，不能为空；材料数与重量独立输入，不再互相换算。
- 编辑回执保存前调用 `POST /buy/raw/receipt/merge-check`。新单号被有效回执占用时，日期、供应商一致则直接合并；不一致由 `ReceiptMergeDialog.vue` 提供“保留当前回执信息”“保留已有回执信息”“取消合并”三个选项，关闭弹窗等同取消，保留编辑内容。
- 确认保存传递 `mergeChoice`（`current` / `existing`）、`mergeTargetId` 和 `mergeTargetUpdatedTime`。后端重新锁定并核对目标；过期确认需要重新保存选择。
- 合并保留目标回执 ID，拼接两边备注（已有备注在前、换行分隔），合并全部明细，原回执逻辑删除。数量统计与库存撤销、重建在同一事务内，失败整体回滚。
- 已删除回执占用的单号在保存事务内替换为内部唯一编号，原单号释放给当前回执；不合并已删除回执的明细。新增单据与有效回执重号仍提示通过编辑合并。
- 部署前执行后端迁移 `sql/buy/20260912_raw_receipt_merge.sql`：兼容此前的多采购单迁移，允许 `purchase_table_id`、`sup_id` 为空并扩展汇总字段长度，备注改为 TEXT 以容纳拼接内容。真实采购关系以明细的 `purchase_item_id` 为准。
- 回执明细和导出显示回执日期、对应采购单号，不显示原材料编号。

- 回执主表、明细及 Excel 导出列顺序为回执日期、回执单号、供应商、采购单号，明细供应商来自关联采购单；新增和编辑回执顶部四个字段在桌面宽度下一行显示，窄屏自动换行。

- 新增回执的采购单下拉隐藏已完成回执的采购单，每次打开重新加载；编辑时保留当前回执已关联的采购单。

- 回执新增明细显示物料编码；增减采购单保留仍选中采购单的已填明细，避免覆盖数量、重量和备注。采购主表与明细在采购单号前显示采购日期。状态搜索支持多选。

- 请购明细“查看”复用关联记录弹窗，按 `requisitionItemId` 查询全部有效采购明细；采购数量紧跟请购重量，板料显示 `purchasedNumber` 张，卷料显示 `purchasedWeight` kg。

- 原材料采购明细操作列提供“结案”，调用 `PUT /buy/raw/purchase/item/{id}/close`，仅将该明细标记为已完成，不改实际采购量、回执量、待回差额和库存。已完成明细隐藏结案按钮，提交中防止重复点击。
- 结案标记持久保存，后续回执增删与状态重算不会取消；主表按全部有效明细汇总完成状态。新增回执不再自动带入已结案明细，编辑已有回执保留原关联。
- 部署前执行后端迁移 `sql/buy/20260923_raw_purchase_close.sql`，再更新后端和前端。
