# 原材料采购

- 订单条目选择器会禁用物料绑定关系中的插件产品，插件只能由快速请购随主产品自动带出。

- 采购单状态统一使用语义 Tag 展示：未回执为“已采购”，部分回执为“部分回执”，全部回执为“已完成”。

- 路由：`/buy/rawPurchase`。
- 默认展示采购主表，可切换为采购明细。
- 一张采购单只能选择一个供应商。
- 点击采购单号或查看按钮展示该主表的全部明细。
- 采购明细视图、查看弹窗和新增/编辑弹窗显示关联订单号。
- 新增、编辑按整张采购单保存，`PO + yyMMdd + 三位流水`由后端统一生成。
- 采购明细可以关联请购明细，请购数量由后端回算。
- 已产生回执的采购单不允许修改或删除。
- 明细列表支持点击整行勾选；顶部汇总所选明细的采购重量、已回执重量和待回重量，并可一键取消选择。
- 页面共用 `../rawProcurement/RawDocumentPage.vue`。

## 后端接口

- `POST /buy/raw/purchase/table/page`
- `POST /buy/raw/purchase/item/page`
- `GET /buy/raw/purchase/{id}`
- `POST /buy/raw/purchase`
- `PUT /buy/raw/purchase`
- `DELETE /buy/raw/purchase/{id}`
- `GET /buy/purchase-document/profile`：获取采购单 PDF 的采购方公司抬头信息。

## PDF 导出

- 主表和明细视图均可按整张采购单打开 PDF 浏览器预览，再使用浏览器工具栏下载或打印。
- 使用 `src/modules/document-pdf` 通用模块，业务适配器和模板位于 `../utils/purchaseDocumentPdf.ts`。
- PDF 使用 240 × 140 mm 横向纸张，公司名称位于“采购单”上方。
- 原材料采购单列为：序号、产品编码、产品名称、产品型号、张数、采购重量、单价、金额、备注；其中产品信息均来自原材料资料。
- 板料显示张数，卷料张数留空；每行金额按“采购重量 × 单价”计算。
- 合计金额为所有明细金额之和，不对单价直接求和；采购详情接口会按当前有效明细实时回算。
- PDF 汇总区在合计金额左侧显示总重量，总重量为所有采购明细的采购重量之和。
- 采购重量、单价、明细金额及合计金额在采购业务中按两位小数保存和显示；原材料基础资料仍保留四位小数精度。
- 表格正文使用加高行距；注意事项使用 1.5 倍行距。备注标签和内容保持同一行，超长内容截断，避免文字换到备注标签下方。
- 供应商地址、联系人和电话由采购单详情按供应商 ID 从供应商资料表补充，空值显示为空白。
