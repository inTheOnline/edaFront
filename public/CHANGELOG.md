# EDA ERP 1.5 更新日志

- 发布版本：1.5.0（1.5）
- 前一版本：1.4.0（1.4）
- 发布日期：2026-09-10
- 来源：当前开发版前后端源码，与 Release 中的 1.4.0 发布源码逐文件对比。

## 采购管理

- 原材料采购升级为请购单、采购单、回执单流程，支持整单新增、编辑和明细关联。
- 新增辅料请购、采购、回执管理及采购首页待办统计。
- 新增快速请购与来源记录，采购明细可关联订单；完善采购数量、重量及回执状态回算。
- 增加采购单 PDF 预览与打印，统一公司抬头、采购单号、金额合计及板料/卷料显示。

## 库存与材料

- 启用库存 V2 页面和接口，增加库存单据、余额、流水、待办及预警管理。
- 完善采购、订单出库等业务与库存的联动，增加库存流水类型设置、关联人员显示及同步控制。
- 完善原材料与产品关联、辅料资料和物料绑定，规范原材料规格及重量字段。
- 调整仓库页面及库存查询展示，清理已被新流程替代的旧接口。

## 生产效率

- 更新员工效率计算与正常速度标准管理，保留生产日报日常录入、编辑及导入。
- 新增效率核实、标准建议批次、标准确认、历史版本及计算结果明细。
- 支持按工序/机台分组建立参考依据，保留人工核实记录和标准快照，区分待核实与样本不足状态。
- 增加月度标准建议生成与启动时缺失数据补全。

## 人事、考勤与工资

- 增加员工编号、考勤调整和工资标准变更记录。
- 更新考勤工时识别与工资计算规则，完善全勤、组长、普工和扣款处理。
- 更新工资计算导入模板、工资明细导出及工作簿公式检查。

## 订单、委外与基础资料

- 完善订单物料状态、出库流程和库存同步控制。
- 增加委外整单操作、退货返工信息、包规快照及委外单 PDF 打印。
- 供应商增加编号和资料字段，按合作状态及新增顺序排序。
- 调整菜单/角色权限为路由节点粒度，并统一业务单据流水号生成。

## 发布说明

- 生产前端 API 使用 /api；生产后端使用 9090；开发服务 9091 保持运行。
- 本次不重跑历史 SQL，不执行库存清零、旧表删除或历史数据回填脚本。
- 数据库当前已存在新版库存、采购、效率等相关表。新版启动会执行代码内既有的效率初始化与月度建议生成。
- 1.4 程序、原生产前端、配置、业务文件及数据库快照已备份，路径见 backup-path.txt。
