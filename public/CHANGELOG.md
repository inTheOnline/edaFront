# EDA ERP 1.5.3 更新日志

- 发布日期：2026-09-16
- 前一版本：1.5.2（含 office-20260915 办公用品更新）
- 发布内容：当前开发端代码，版本标记统一为 1.5.3。

## 新增功能

- 包装日报：按日期、员工和共用工时分组录入多条包装明细，支持整组编辑、筛选、合计及逻辑删除；不参与生产效率计算。
- 客户退货：支持关联订单或直接选产品录入退货，回算净出货数量，可同步不良品库存，并支持退货单号修改。
- PDF 盖章与签名：基础管理工具箱可导入 PDF、拖动定位印章和签名，支持两组骑缝章、页面预览及导出；原文件不会被覆盖。
- 委外首页：使用真实业务数据展示总览、供应商待回排行及按月/按日趋势，供应商和产品筛选联动。

## 调整与修复

- 委外批量新增回执统一保存为已提交状态，统计按有效且已提交回执计算。
- 优化原材料请购、采购单据展示和金额处理；采购 PDF 汇总展示总重量。
- 调整工资标准审批与变更记录条件，完善工资导入数值读取及导出处理。
- 修复基础管理首页与路由管理名称冲突，完善菜单名称处理。
- 出库列表及导出按单据日期倒序、同日按明细 ID 倒序。
- 保留 1.5.2 办公用品更新，包括三位小数单价、逻辑删除及相关业务流程。

## 数据与部署

- 继续使用 D:/EDA_ERP/prod/files 中的现有生产业务文件。
- 新增盖章工具依赖的 6 个印章/签名文件，保存在后端业务目录 base/seals，不进入前端公开资源目录。
- 发布前已备份生产程序、前端、业务文件、启动器、Nginx 配置及数据库。
- 所需包装日报表、办公用品字段和库存配置已核对；本次不执行历史 SQL，不覆盖恢复生产数据库。
